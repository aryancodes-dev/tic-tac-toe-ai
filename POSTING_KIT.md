## Full description (README / portfolio / LinkedIn post)
Tic-Tac-Toe with AI is Project #02 of my 100+ AI Projects series. You play as X against an AI that uses the Minimax algorithm. On Impossible mode the AI never loses — the best you can do is draw, which is exactly how a perfect Tic-Tac-Toe player should play.

It also has Easy and Medium modes for practice, a Vs Friend mode for two players on one phone, a live scoreboard, and a winning-line highlight. The web version installs as an app on your phone, and the same Minimax brain is included as a Python CLI game.
